HEX ROUTER DESIGNER v1
======================

Запуск
------
1. Скопируйте Hex_Router_Designer.html в любую папку.
2. Откройте файл двойным щелчком в современном браузере.
3. Интернет, установка, локальный сервер и дополнительные файлы не нужны.

Создание конструкции
--------------------
- В пустом проекте кликните в любом месте рабочей области, чтобы поставить первый шестигранный модуль.
- После этого новые модули можно добавлять только в подсвеченные соседние ячейки.
- Клик по установленному модулю выбирает его.
- «Удалить» удаляет выбранный модуль только если оставшаяся конструкция остаётся связной.
- «Очистить» удаляет всю конструкцию.
- Доступны Undo/Redo, панорамирование, колесо/жест масштабирования и «Вписать».

START / END
-----------
- AUTO автоматически выбирает две допустимые точки на нижнем внешнем контуре.
- «Назначить START» и «Назначить END» позволяют вручную переопределить любую точку.
- START: +V, GND, DATA IN.
- END: +V, GND.
- DATA проходит по единой последовательной трассе от START к END.
- Питание предполагается подавать с обоих концов от одной согласованной системы питания с общей землёй контроллера.

Трассировка
-----------
Доступны два критерия:
1. Минимум повторов — минимизирует число повторно пройденных сегментов.
2. Избегать общих сторон — штрафует повторное прохождение сторон, общих для двух соседних модулей.

Основной проход отображается сплошной линией. Повторные проходы — пунктиром.
Можно листать маршрут по шагам, запускать и останавливать анимацию, включать номера шагов и диагностику нечётных узлов.

Расчёты
-------
Задаются:
- длина стороны по оси LED-ленты, мм;
- плотность LED/м;
- мощность ленты, Вт/м;
- напряжение 5/12/24 В;
- запас мощности блока питания.

Программа рассчитывает длину уникального коридора, добавочную длину повторов, общую длину ленты, ориентировочное количество LED, мощность, ток, рекомендуемую мощность БП, процент повторной трассы и расстояние START-END.

Файлы
-----
- «Сохранить JSON» сохраняет редактируемый проект.
- «Открыть JSON» загружает проект версии 1 и проверяет его связность и параметры.
- «Экспорт SVG» сохраняет самостоятельную техническую схему маршрута.
- examples/reference-construction.json — пример из 8 модулей, построенный по исходной конфигурации пользователя.

Ограничения и безопасность
--------------------------
Электрические расчёты носят рекомендательный характер. Программа не моделирует падение напряжения, нагрев, сечение проводов, допустимый ток дорожек, конкретные предохранители или сертификационные требования. Перед изготовлением необходимо отдельно проверить эти параметры.
Не объединяйте выходы двух независимых блоков питания параллельно на одну шину без схемы, рассчитанной на совместную работу источников.

Редактирование геометрии: после первого модуля нажимайте знак «+» на любой свободной грани существующего шестигранника. Один «+» добавляет один соседний шестигранник за этой гранью.
