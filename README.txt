HEX ROUTER DESIGNER v1
======================

Запуск
------
1. Скопируйте index.html в любую папку.
2. Откройте файл двойным щелчком в современном браузере.
3. Интернет, установка, локальный сервер и дополнительные файлы не нужны.

Создание конструкции
--------------------
- В пустом проекте кликните в любом месте рабочей области, чтобы поставить первый шестигранный модуль.
- После этого новые модули добавляются знаком «+» на свободной грани уже установленного шестигранника.
- Один знак «+» добавляет ровно один соседний шестигранник за выбранной гранью.
- Переключатель «Ориентация» задаёт вертикальное или горизонтальное положение шестигранников. На пустом поле он задаёт ориентацию будущей конструкции; на заполненном поле разворачивает всё поле на 90 градусов и пересчитывает нижние START/END-кандидаты.
- Постоянного активного/выбранного шестигранника нет.
- Для удаления нажмите «Удалить», затем нажмите на нужный шестигранник. Модуль удалится только если оставшаяся конструкция останется связной; после успешного удаления режим выключается. Esc отменяет режим удаления.
- «Очистить» удаляет всю конструкцию.
- Доступны Undo/Redo, панорамирование, колесо/жест масштабирования и «Вписать».

START / END
-----------
- AUTO автоматически выбирает две допустимые точки на нижнем внешнем контуре с учётом текущей ориентации поля.
- «Назначить START» и «Назначить END» позволяют вручную переопределить любую допустимую нижнюю точку.
- Если после поворота вручную заданная точка перестала быть допустимой нижней точкой, программа возвращается в AUTO и показывает предупреждение.
- START: +V, GND, DATA IN.
- END: +V, GND.
- DATA проходит по единой последовательной трассе от START к END.
- Питание предполагается подавать с обоих концов от одной согласованной системы питания с общей землёй контроллера.

Трассировка
-----------
Доступны два критерия:
1. Минимум повторов — минимизирует число повторно пройденных сегментов.
2. Избегать общих сторон — штрафует повторное прохождение сторон, общих для двух соседних модулей.

Основной проход отображается сплошной линией. Повторные проходы — пунктиром.
«Анимация» показывает маршрут последовательно от START к END. «Пауза» останавливает на текущем шаге; повторное нажатие «Анимация» продолжает с этого места. После достижения END новое нажатие «Анимация» запускает маршрут снова от START. Ползунок и кнопки ◀/▶ позволяют просматривать маршрут вручную.

Расчёты
-------
Главные геометрические параметры LED-ленты:
- количество сегментов (шагов между соседними местами возможного разреза) на одну сторону шестигранника;
- плотность LED/м.

Длина стороны вычисляется автоматически:
side_mm = segments_per_side × 1000 / LED_per_m

Также задаются:
- мощность ленты, Вт/м;
- напряжение 5/12/24 В;
- запас мощности блока питания.

Программа рассчитывает длину стороны, длину уникального коридора, добавочную длину повторов, общую длину ленты, ориентировочное количество LED, мощность, ток, рекомендуемую мощность БП, процент повторной трассы и расстояние START-END.

Файлы
-----
- «Сохранить JSON» сохраняет редактируемый проект версии 2, включая ориентацию и количество сегментов на сторону.
- «Открыть JSON» загружает проекты версии 2, а также старые проекты версии 1. Для v1 ориентация принимается вертикальной, а число сегментов вычисляется из старых side_mm и LED/м; при необходимости значение округляется с предупреждением.
- «Экспорт SVG» сохраняет самостоятельную техническую схему маршрута в текущей ориентации.
- examples/reference-construction.json — пример из 8 модулей в старом формате v1; он также служит проверкой обратной совместимости.

Ограничения и безопасность
--------------------------
Электрические расчёты носят рекомендательный характер. Программа не моделирует падение напряжения, нагрев, сечение проводов, допустимый ток дорожек, конкретные предохранители или сертификационные требования. Перед изготовлением необходимо отдельно проверить эти параметры.
Не объединяйте выходы двух независимых блоков питания параллельно на одну шину без схемы, рассчитанной на совместную работу источников.
